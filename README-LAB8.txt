How to run backend:
1. Open terminal in project root
2. Run: mvnw.cmd spring-boot:run   (Windows)
   or  ./mvnw spring-boot:run      (Mac/Linux)

How to run frontend:
1. Open terminal in frontend folder
2. Run: npm install
3. Run: npm run dev
4. Open the Vite URL shown in terminal

Notes:
- This Lab 8 version keeps the same backend/frontend structure as Lab 7 so it should behave similarly on the professor's PC.
- The cart is stored in browser localStorage to avoid extra backend setup.
- Product detail pages were added for both books and magazines.
- Mobile starter files are included in /mobile.
